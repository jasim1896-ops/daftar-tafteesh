# دفتر التفتيش الميداني

تطبيق جوال لتسجيل زيارات التفتيش البيئي (الموقع، الوقت، الإحداثيات، المشاهدات، الصور)، يطلّع ملف إكسل كامل فيه التقارير الأسبوعية والشهرية والدورية جاهزة للإرسال.

- **التطبيق:** https://jasim1896-ops.github.io/daftar-tafteesh/
- **التثبيت على الآيفون:** افتح الرابط في Safari، اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».

البيانات والصور تنحفظ على جهازك فقط، وما تنرفع على هذا المستودع.

تفاصيل المشروع والقرارات والخطوة الجاية موجودة في `CLAUDE.md`.
